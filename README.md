# 🚀 Git & GitHub Implementation on AWS EC2

## 📌 Project Overview

This project demonstrates the practical implementation of **Git and GitHub on an AWS EC2 Linux server**.

The objective is to understand how developers manage source code using Git, collaborate through GitHub, and work with a Linux-based cloud environment using AWS EC2.

## 🛠️ Technologies Used

* ☁️ AWS EC2
* 🐧 Linux
* 🔧 Git
* 🐙 GitHub
* 🌐 HTML
* 🎨 CSS

## 🎯 Project Objectives

* Understand Git version control
* Configure Git on an AWS EC2 instance
* Create and manage a Git repository
* Track project changes
* Create commits
* Create and manage branches
* Connect a local repository with GitHub
* Push and pull code between GitHub and EC2
* Understand a basic real-world DevOps workflow
